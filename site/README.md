# aiinsuregenie.com

Static marketing site and guides, built with a dependency-free Node script.

- Build: `node build.js` (outputs to `dist/`)
- Add a guide: create `content/posts/<slug>.md` with `title`, `description`, `date` frontmatter, then rebuild.
- Deployed on Vercel project `aiinsuregenie-site` (root directory `site`, build `node build.js`, output `dist`).
